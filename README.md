# Snake — консольная игра

Классическая «Змейка» в терминале. Управляйте стрелками, ешьте еду `*`, избегайте стен и собственного хвоста. Поле перерисовывается на месте.

## Запуск

Нужен Python 3.10 или новее. Зависимостей для запуска нет.


```bash
python snake.py --width 20 --height 15 --speed 8
```

Параметры: ширина и высота поля, начальная скорость в ходах за секунду. Поддерживается команда `--help`.

Управление: стрелки — движение; пробел — пауза; `q` — выход. Каждые 5 съеденных яблок повышается уровень и увеличивается скорость. После окончания игры показывается счёт и предлагается начать заново.

Для разработки установите `uv`, затем выполните:

```bash
uv sync --all-groups
uv run python snake.py --width 20 --height 15 --speed 8
```

## Проверки

Правила игры вынесены в `snake_game/logic.py` и тестируются отдельно от терминала и клавиатуры.

```bash
uv run pytest
uv run ruff check .
uv run ruff format --check .
uv run mypy --strict snake_game snake.py tests
```

GitHub Actions запускает тесты, Ruff и mypy при каждом push и pull request.

## Как устроена программа

- `Snake` хранит тело и выполняет перемещение, рост и проверку самопересечения.
- `Game` отвечает за еду, счёт, уровень, паузу и столкновения.
- `terminal.py` обрабатывает ввод и отрисовывает поле; на Unix включает режим немедленного ввода, на Windows читает стрелки через `msvcrt`.
